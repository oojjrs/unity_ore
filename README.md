# UnityOre

OOJJRS Reporter 서버로 게임 보고서, 사용 이벤트와 매치 검증 데이터를 전송하기 위한 Unity 패키지다.

## 패키지 정보

- 패키지 ID: `com.oojjrs.ore`
- 패키지 루트: `Packages/src`
- 런타임 어셈블리: `oojjrs.ore`
- 최소 Unity 버전: `6000.0`

`ReporterClient`를 통해 Bearer 인증 보고서, 진단 이벤트와 매치 검증 데이터를 전송할 수 있다. 보고서에는 스크린샷, 로그 같은 첨부파일을 함께 보낼 수 있다.

패키지 문서는 [Packages/src/README.md](Packages/src/README.md)를 참고한다.
